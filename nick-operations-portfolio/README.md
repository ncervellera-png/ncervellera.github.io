# Northstar Ops

Northstar Ops is Nick's portfolio and lightweight operations workspace. It turns a meeting topic into an operating record with five required fields:

1. Decision made
2. Remaining evidence
3. Owner
4. Due date
5. Next decision gate

The app also connects initiatives to objectives and key results, shows a high-level dashboard, and presents selected work as portfolio case studies.

## What works now

- Dashboard metrics calculated from the decision register
- Card-based decision board with search and project filters
- Add, edit, move, and delete decision records
- Add objectives, key results, and portfolio projects
- Portfolio presentation mode
- Local automatic saving
- JSON backup and restore
- Responsive layout for desktop and phone
- GitHub Pages publishing workflow

## Important data note

This version is intentionally server-free. Edits stay in the current browser on the current device. They are not automatically shared with Eddie or other team members. Download a backup after important changes.

For a shared production workspace, add sign-in, a hosted database, role-based access, audit history, and private/public separation. Keep the public portfolio separate from confidential operations records.
